# דמו: מערכת לידים לעסק מקומי

דף נחיתה של עסק בדוי ("אוויר נקי", טכנאי מיזוג בעמק חפר). כשממלאים את הטופס, נפתח מסך שמראה את הודעת הוואטסאפ שהלקוח מקבל ואת מה שקורה במקביל מאחורי הקלעים.

הדף עובד בשני מצבים:

| מצב | מתי | מה קורה |
| --- | --- | --- |
| דמו בלבד | `webhookUrl` ריק (ברירת מחדל) | השיחה בוואטסאפ מוצגת רק על המסך. לא נשלח שום דבר. |
| חי | `webhookUrl` מוגדר | הליד נשלח ל-n8n, ומי שמילא את הטופס מקבל הודעת וואטסאפ אמיתית. |

ההגדרות נמצאות בראש ה-`<script>` ב-`index.html`, באובייקט `CONFIG`.

---

## העלאה לאוויר (Netlify)

1. ב-Netlify: Add new site, ואז Import from GitHub ובחירת הריפו `growth-os`.
2. Base directory: `demos/leads-demo`. אין פקודת בנייה.
3. אפשר להשאיר את הכתובת של Netlify, או לחבר תת-דומיין כמו `demo.multibrawn.co.il`.

הדף מסומן `noindex`, כדי שגוגל לא יאנדקס עסק בדוי.

## חיבור n8n (לגרסה החיה)

מבנה ה-workflow:

```
Webhook (POST /lead)
  → Google Sheets: Append row          (גיליון "לידים")
  → WhatsApp: הודעה ללקוח              (phone_intl)
  → WhatsApp: התראה לבעל העסק
  → Wait 3h → בדיקה אם הסטטוס עדיין "חדש" → תזכורת לבעל העסק
```

השדות שהטופס שולח:

```json
{
  "name": "דנה כהן",
  "phone": "0521234567",
  "phone_intl": "972521234567",
  "service": "התקנת מזגן חדש",
  "source": "facebook",
  "campaign": "",
  "page": "https://…",
  "submitted_at": "2026-10-06T19:05:00.000Z"
}
```

`source` ו-`campaign` נלקחים מ-`utm_source` ומ-`utm_campaign` בכתובת. מומלץ לשלוח לכל עסק לינק עם `?utm_source=whatsapp`, וכך הדוח החודשי יראה מאיפה הגיעו הפניות.

### הגדרות בצד n8n

- **CORS:** בצומת ה-Webhook מגדירים את Allowed Origins לדומיין של הדף. אחרת הדפדפן חוסם את הבקשה.
- **ספק וואטסאפ:** WhatsApp Cloud API של Meta היא האפשרות הרשמית. הודעה ראשונה ללקוח שלא כתב לעסק קודם דורשת תבנית (Template) מאושרת. שירותים לא רשמיים מסתכנים בחסימת המספר, ולכן לא משתמשים בהם אצל לקוחות משלמים.
- **אבטחה:** כתובת ה-webhook גלויה בקוד הדף. לכן ב-n8n מסננים טלפון לא תקין ומגבילים כמות בקשות. שדה ה-honeypot (`company`) כבר עוצר בוטים פשוטים בצד הדפדפן.

### נוסח תבנית מומלץ (לאישור ב-Meta)

```
היי {{1}}, כאן {{2}} 👋
קיבלנו את הפנייה שלך בנושא: {{3}}.
נחזור אליך בשעתיים הקרובות.
```

## התאמה ללקוח אמיתי

מה מחליפים כשהופכים את הדמו לדף של לקוח:

1. שם העסק, הלוגו והצבעים (משתני `:root` בראש ה-CSS).
2. הכותרת, השירותים, השאלות הנפוצות ואזורי השירות.
3. ב-`CONFIG`: `webhookUrl`, `whatsappNumber` ו-`businessName`.
4. מוחקים את פס הדמו העליון ואת שכבת "מאחורי הקלעים". אצל לקוח אמיתי מוצגת הודעת תודה פשוטה.
5. מסירים את `noindex` מה-`<head>` ומ-`netlify.toml`.
