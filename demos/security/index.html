ככה מתנהל פרויקט

מחיר לעסק נותנים רק אחרי שראינו את המקום. זה חוסך הפתעות לשני הצדדים.

  1. פנייה בצ׳אטשם החברה, סוג המקום, ההיקף ומתי צריך.
  2. תוכניות בוואטסאפשרטוט, כתב כמויות או מסמכי מכרז, אם יש.
  3. סיור בשטחבודקים כניסות, מסלולי כבלים ומקום לארון.
  4. הצעה בכתבציוד, עבודה ולוח זמנים, סעיף אחרי סעיף.
  5. התקנה ומסירהבדיקה, תיק מסירה והדרכה לצוות שלכם.
