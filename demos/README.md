## הצ'אט המשותף: `shared/leadbot.js`

כל דפי הנישה משתמשים באותו צ'אט. הוא מתוסרט (בלי AI ובלי שרת): שואל כמה שאלות, בודק שהטלפון תקין, מציג סיכום ופותח וואטסאפ עם כל הפרטים.

```html
<script src="../shared/leadbot.js"></script>
<script>
  const bot = LeadBot.init({
    whatsapp: "9725XXXXXXXX", name: "שם · תחום", initial: "ש", launcher: "טקסט לכפתור",
    greet: "הודעת פתיחה",
    steps: [
      { key: "issue", label: "תקלה", ask: "מה קרה?", chips: ["א", "ב"] },
      { key: "name", label: "שם", ask: "איך קוראים לכם?", input: "text" },
      { key: "phone", label: "טלפון", ask: "מספר?", input: "tel" },
    ],
    closing: (d) => "הודעת סיום",
    summary: (d) => "הטקסט שנשלח בוואטסאפ",
  });
  // bot.open({ issue: "א" }) פותח את הצ'אט עם תשובה ראשונה מוכנה
</script>
```

- `data-open-bot` על כפתור פותח את הצ'אט. `data-wa="טקסט"` על קישור הופך אותו לקישור וואטסאפ.
- הצבעים והפינות נקבעים במשתני CSS בדף: `--bot-bg`, `--bot-fg`, `--bot-accent`, `--bot-radius` וכו'.
- `onDone: LeadPhone("#ph-msg")` מעדכן את מוקאפ הטלפון (`shared/phone.css`) בפנייה שהגולש מילא, כדי שיראה מה בעל העסק מקבל.
- ללקוח משלם, הצ'אט שולח את הפרטים גם למערכת (Cloud API הרשמי), לא רק דרך קישור וואטסאפ.

## תמונות מתחלפות: `shared/photoslots.js`

בכל דפי הנישה יש כפתור "לנסות עם התמונות שלכם". במצב עריכה לוחצים על מסגרת (`.ps[data-slot]`) ומעלים תמונה, או גוררים קובץ. גוררים כדי למקם, והסליידר מגדיל. טקסטים עם `data-edit` נערכים במקום. הכול נשמר רק בדפדפן של מי שערך (IndexedDB), ולא נשלח לשום מקום. `?edit` בכתובת פותח ישר במצב עריכה.

ככה מראים לבעל עסק את הדף שלו עם התמונות שלו, כבר בשיחה הראשונה.

## הנציג החכם בעמוד הראשי: `shared/aibot.js` + `netlify/functions/chat.mjs`

צ'אט AI אמיתי (Claude) שמכיר את החבילות, המחירים והדמואים. הוא עונה בעברית קצרה, מוסיף כפתורים (דמו מתאים, מחירון, וואטסאפ לכפיר עם סיכום מוכן), ומראה לבעל עסק איך ייראה נציג באתר שלו.

- **מפתח:** ב-Netlify, Site configuration ← Environment variables ← `ANTHROPIC_API_KEY`. לא שמים את המפתח בקוד ולא בצ'אט.
- **בלי מפתח:** הצ'אט עובר ל"מצב הדגמה" עם תשובות מתוסרטות, והדף לא נשבר.
- **מודל:** `claude-opus-5-5` כברירת מחדל. אפשר להחליף עם משתנה `CHAT_MODEL` (למשל `claude-haiku-5-5`, זול יותר).
- **הגבלות:** עד 600 תווים להודעה, 20 הודעות לשיחה, 30 בקשות ל-10 דקות לכל IP (לכל מופע של הפונקציה), ורק מהאתר עצמו.
- **מה הבוט יודע:** הפרומפט נמצא בראש `netlify/functions/chat.mjs`. כשמחיר משתנה ב-`index.html`, מעדכנים גם שם.

## העלאה ל-Netlify

1. Netlify ← Add new site ← Import from GitHub ← `growth-os`.
2. ההגדרות נקראות מ-`netlify.toml` בשורש הריפו: Base directory `demos`, בלי בנייה. אם בממשק כתוב משהו אחר, להשאיר את השדות ריקים או לשים `demos`.
3. כל push לענף שמחובר מעדכן את האתר. ההגדרות ב-`netlify.toml`.

## לפני שמפרסמים

- [x] ב-`index.html`, באובייקט `CONFIG`: `whatsappNumber` מוגדר (972526359513).

כל דפי הדמו (חוץ מהעמוד הראשי) מסומנים `noindex`, כדי שגוגל לא יאנדקס עסקים בדויים. העמוד הראשי, `/all/`, `/film/` והדפים המשפטיים פתוחים לאינדוקס, ורשומים ב-`sitemap.xml` (עם `robots.txt`, `favicon.svg`, `apple-touch-icon.png` ו-`og-image.jpg` בשורש).
